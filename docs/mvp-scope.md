# MVP Scope

This defines the first version of Rosarium focused on speed, simplicity, and immediate usability.

## In Scope
- QR landing page
- Start prayer immediately
- Select intention
- Guided rosary flow (step-by-step UI progression)
- Mystery of the day logic
- English / Spanish toggle
- Local progress tracking (no login required)

## Out of Scope
- Payments
- User accounts (initially optional)
- Distributor tools
- Analytics dashboards
- Notifications
- Social features

## Success Criteria
- User can complete a guided prayer within 3–5 minutes
- Experience works smoothly on mobile
- Content loads instantly
- No login required to start
