# MVP Scope

This defines the first version of Rosarium focused on speed, simplicity, and immediate usability.

## In Scope
- QR landing page
- Start prayer immediately
- Select intention
- Guided rosary flow (step-by-step UI progression)
- Mystery of the day logic
- English / Spanish toggle
- Local progress tracking (no login required)

## Out of Scope
- Payments
- User accounts (initially optional)
- Distributor tools
- Analytics dashboards
- Notifications
- Social features

## Success Criteria
- User can complete a guided prayer within 3–5 minutes
- Experience works smoothly on mobile
- Content loads instantly
- No login required to start

## Definitions

- QR Landing Page: First screen shown after scanning a QR code
- Intention: The purpose of the prayer (e.g., Healing, Gratitude)
- Guided Flow: Step-by-step progression through prayers with UI controls
- Completion Screen: Final screen after finishing a prayer session
- Session: One full or partial prayer experience

## Data Sources

- Prayer text will be loaded from static JSON files
- Mystery of the day is determined by day-of-week mapping
- Intentions are predefined from a static list
