# Rosarium

Rosarium is a mobile-first web app that transforms a simple moment (like receiving a rose) into a guided prayer experience.

## Core Idea
A user scans a QR code attached to a bouquet → lands on Rosarium → is guided through a short or full rosary → optionally returns daily.

## MVP Features
- QR landing page
- Guided rosary (step-by-step)
- Mystery of the day
- Intention selection
- Bilingual (English / Spanish)
- Local progress tracking (no login required initially)

## Target User
- Gift receiver (flowers)
- Catholic / spiritually open user
- Spanish-first audience (Ecuador, Miami)

## Tech Stack (MVP)
- Frontend: Next.js
- Content: Static JSON
- Persistence: LocalStorage
- Backend: Not required initially

## Goal (Next 60 Days)
- Working mobile experience
- Clean UI
- Demo-ready for partners (distributors, farms)

## Out of Scope (MVP)
- Payments
- Complex accounts
- Distributor dashboards
- Inventory systems
